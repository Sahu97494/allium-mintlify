The schema `defillama.tvl`contains these tables:

| Table                             | Description                                      |
|----------------------------------|--------------------------------------------------|
| historical_agg_token_amounts     | Daily historical token amounts per protocol      |
| historical_agg_token_values      | Daily historical token values per protocol       |
| historical_agg_tvl               | Daily historical TVL per protocol                |
| historical_token_amounts_per_chain | Daily historical token amounts per protocol per chain |
| historical_token_values_per_chain | Daily historical token values per protocol per chain |
| historical_tvl_per_chain         | Daily historical TVL per protocol per chain      |
