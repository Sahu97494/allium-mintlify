---
title: "Fees"
---

`solana.raw.fees`provides inforrmation on base and priority fees of solana transactions. More info about transactions fees can be found [here](https://solana.com/id/docs/core/fees).

Note that it only contains transactions with non-zero priority fees. For all other transactions, `priority_fee=0, base_fee=tx_fee`
