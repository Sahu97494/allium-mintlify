title: "Decoded Instructions"

Decoded instructions can be found in `solana.decoded.instructions`.

The availability of decoded instructions for a program depends heavily on having updated & backwards compatible IDLs. Some programs might not have backwards compatible IDLs, so updating IDLs to the latest available will not help with errors in decoding.

If you need a program decoded with either a new IDL, or backfill a historical period with a specific old IDL, please reach out.

If you require tx-level detail for records in this table, see [here](/historical-chains/supported-blockchains/solana#transaction-level-columns) for more info.
