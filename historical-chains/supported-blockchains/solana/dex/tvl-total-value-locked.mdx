---
title: "TVL (Total Value Locked)"
description: This table contains TVL information for various dex pools.
---

`solana.dex.tvl` currently includes the following dex/protocols

| Project | Protocol       |
| ------- | -------------- |
| meteora | meteora-dlmm   |
| orca    | orca-whirlpool |
| phoenix | phoenix        |

The data tracks changes to a pool's TVL at the **transaction** level, not instruction level
