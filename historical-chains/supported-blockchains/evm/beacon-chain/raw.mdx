The beacon raw schema includes the following tables:

| Table                    | Description                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| blocks                   | Essential block level data.                                                                              |
| withdrawals              | Validator withdrawals data from Beacon Chain. Includes partial and full withdrawal.                      |
| deposits                 | Deposits into the ETH staking [deposit contract](https://eth2book.info/capella/part2/deposits/contract). |
| attestations             | Attestation data for each slot.                                                                          |
| block\_rewards           | Slot-level rewards for blocks that were successfully proposed.                                           |
| total\_rewards           | Epoch-level attestation rewards for active validators.                                                   |
| ideal\_rewards           | Epoch-level ideal rewards from attestations for active validators.                                       |
| sync\_committee\_rewards | Slot-level rewards for selected validators participating in the sync committee.                          |
