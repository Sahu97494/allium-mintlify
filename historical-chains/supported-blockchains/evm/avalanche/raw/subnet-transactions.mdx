---
title: "Subnet Transactions"
description: "Avalanche import and export chain transactions from p-chain and x-chain to c-chain."
---

<Info>
Note: `avalanche.raw.subnet_transactions` is currently in Beta format, with data being backfilled.
</Info>

The table columns may change over time.

* This model decodes the `blockExtraData` field, which appends import/export transactions to/from c-chain

* The decoding was based on Avalanche's serialisation across all 3 subnets:

  * [https://docs.avax.network/reference/avalanchego/c-chain/txn-format](https://docs.avax.network/reference/avalanchego/c-chain/txn-format)

* This model was created from the c-chain's perspective - a `pvm_export` would be a c-chain -> to p-chain
