Our Base raw schema contains the following tables:

| Schema | Description                      | Tables                                                    |
| ------ | -------------------------------- | --------------------------------------------------------- |
| Raw    | Raw blockchain data.             | blocks, transactions, logs, traces                        |
| Raw+   | Deployed contracts with bytecode | contracts, erc20\_tokens, erc721\_tokens, erc1155\_tokens |
