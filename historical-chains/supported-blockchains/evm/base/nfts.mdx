## NFT Trades

NFT trades provide aggregate and marketplace-specific trades from marketplaces and protocols indexed by Allium.

The trades tables are index from a combination of call data and event logs from NFT Marketplaces.

## NFT Mints

NFT mints table provides enriched data on on-chain NFT mints.

The aggregated mints table contains standard and contract-specific mints (e.g. Seadrop, NewCloneTicker, etc) enriched with minting currency and cost in USD denomination. Mints associated with a particular platform (e.g. magic eden, opensea) are labeled whenever possible.
