---
title: "ERC1155 Transfers"
---

The ERC1155 Token Transfers table records all transactions made with tokens that adhere to the ERC1155 standard.

### Table Columns

<table><thead><tr><th width="268.5">Column Name</th><th>Description</th></tr></thead><tbody><tr><td>event_type</td><td>Type of transfer event for ERC1155 tokens. This can either be a single or batch transfer.</td></tr><tr><td>operator</td><td>Address of the ERC1155 operator.</td></tr><tr><td>from_address</td><td>Address where the token is being transferred from.</td></tr><tr><td>to_address</td><td>Address where the token is being transferred to.</td></tr><tr><td>token_address</td><td>Token address of the asset transferred.</td></tr><tr><td>token_name</td><td>Token name.</td></tr><tr><td>token_symbol</td><td>Token symbol.</td></tr><tr><td>token_id</td><td>Unique ID of the ERC token.</td></tr><tr><td>raw_amount_str</td><td>Amount of token moved, unnormalized, in string (to retain precision).</td></tr><tr><td>raw_amount</td><td>Amount of tokens moved, unnormalized.</td></tr><tr><td>amount_str</td><td>Amount of token moved, normalized, in string (to retain precision).</td></tr><tr><td>amount</td><td>Amount of token moved, normalized.</td></tr><tr><td>transaction_from_address</td><td>The address of the sending party of this transaction.</td></tr><tr><td>transaction_to_address</td><td>The address of the receiving party of this transaction (could be a contract address).</td></tr><tr><td>transaction_hash</td><td>Transaction hash that this transfer belongs to.</td></tr><tr><td>log_index</td><td>The log index that corresponds to this transfer.</td></tr><tr><td>block_timestamp</td><td>The time when the block that contains this transaction was included on the blockchain.</td></tr><tr><td>block_number</td><td>The block number that the corresponding transaction of this transfer belongs to.</td></tr><tr><td>block_hash</td><td>The block hash that the corresponding transaction of this transfer belongs to.</td></tr><tr><td>unique_id</td><td>Unique id generated to each transfer.</td></tr></tbody></table>
