Our Base balances schema currently supports ETH and ERC20 balances and latest balances.

<Info>
Note that native ETH on Base uses the null address `0x0000000000000000000000000000000000000000` as token\_address.
</Info>

<table><thead><tr><th width="187">Table</th><th> Description</th><th>Assets Supported</th></tr></thead><tbody><tr><td>balances</td><td>Block-level balances of all assets</td><td>ETH, ERC20</td></tr><tr><td>balances_latest</td><td>Latest-balances of all assets </td><td>ETH, ERC20 </td></tr></tbody></table>
