Raw Ethereum data tables allow you to query for any transaction, block, log or trace across the Ethereum blockchain. These tables require basic to intermediate blockchain knowledge to query effectively.

**Additional Resources:**

* [Intro to Ethereum](https://ethereum.org/en/developers/docs/intro-to-ethereum/)

* [Blocks](https://ethereum.org/en/developers/docs/blocks/)

* [Transactions](https://ethereum.org/en/developers/docs/transactions/)

Our Ethereum raw schema contains the following tables:

<table><thead><tr><th width="138.00000000000003">Schema</th><th width="340">Description</th><th>Tables </th></tr></thead><tbody><tr><td>Raw</td><td>Raw blockchain data.</td><td>blocks, transactions, logs, traces</td></tr><tr><td>Raw+</td><td>Deployed contracts with bytecode and ERC token data.</td><td>contracts, erc20_tokens, erc721_tokens, erc_1155_tokens </td></tr></tbody></table>
