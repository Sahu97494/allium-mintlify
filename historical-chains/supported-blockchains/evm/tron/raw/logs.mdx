---
title: "Logs"
---

<Info>
* The transaction hash in this table contains a 0x prefix.
</Info>

Logs (or event logs), is a way for [smart contracts](https://ethereum.org/en/developers/docs/smart-contracts/#what-is-a-smart-contract) to communicate with the outside world by "documenting" small pieces of information. Event logs allow other people to know that something has happened without them having to query the contract directly.

The most common form of event logs today are TRC20 token transfer events.

To learn more, please refer to the following articles:

* [Official TRON Documentation](https://developers.tron.network/docs/event)

### Sample Query&

Querying the event logs from the example given below.

```sql
select *
  from tron.raw.logs
where 1=1 
and transaction_hash ='0x84e1db9240482a20090d5bc9b1a3a4a3fc503eb05d821b3e5c3cc8bd5d031938'
```
