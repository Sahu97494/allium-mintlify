Our Tron raw data can be separated into two main categories:

| Category       | Description                                                                | Important Notes                  |
| -------------- | -------------------------------------------------------------------------- | -------------------------------- |
| EVM Compatible | Raw transaction, blocks, logs data from evm-compatible JSON-RPC Endpoints. | 0x prefix in transaction hash    |
| Tron Native    | Native tron transactions and internal transactions from Tron's native API. | No 0x prefix in transaction hash |

Tron native endpoints would contain data that is not available in the evm-compatible JSON-RPC endpoints.
