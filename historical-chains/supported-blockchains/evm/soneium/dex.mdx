---
title: "Overview"
description: Allium Decentralized Exchange (DEX) data from EVM chains.
---

Decentralized Exchanges (DEXs) are crucial blockchain infrastructure that enable permissionless trading of tokens through automated market makers (AMMs) and liquidity pools, eliminating the need for traditional intermediaries.

Allium provides comprehensive DEX data covering everything from individual swap events to aggregator trades, allowing users to analyze trading activity, liquidity dynamics, and market behavior across various DEX protocols.

| Models                  | Description                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------ |
| DEX Trades              | DEX swaps executed by liquidity pools. Does not include aggregator trades.           |
| DEX Pools (**coming soon**)              | DEX Pools deployed by factory addresses. Typically includes protocol we have indexed |
| DEX Aggregator Trade (**coming soon**)    | DEX swaps executed by aggregators and meta-aggregator                                |
| DEX Events (**coming soon** )              | DEX pool events for uniswap\_v3 and uniswap\_v2 protocols                            |
| DEX OrderFlow (**coming soon**)             | DEX aggregator trades and trades combined to detect frontend volume flow             |
| DEX Token Prices Hourly | DEX token prices drived from dex.trades                                              |
