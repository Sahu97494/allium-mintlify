Our B3 assets schema includes Native and ERC Balances and Token Transfers.

| Table           | Description                                                                    |
|-----------------|--------------------------------------------------------------------------------|
| Balances        | Block level balances of Native and ERC20 tokens                                |
| Balances Latest | Latest balances of Native and ERC20 tokens                                     |
| Token Transfers | Records transfers of Native, ERC20, ERC721 and ERC1155 between addresses.      |
| Credit Debit    | Credit and debit entries for assets                                            |
