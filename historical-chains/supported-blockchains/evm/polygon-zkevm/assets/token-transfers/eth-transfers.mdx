---
title: "ETH Transfers"
---

Contains transfers of native gas token from traces and gas payment from initiating a transactions. We identify successful transfers by looking for trace calls that deduct native gas token for movement of native tokens from an address.

For transaction fees, we compute the priority and base fees (if applicable) and assign the transaction sender as the `from_address` and the recipient to the respective destination (miner, sequencer, burn address, etc).

<Info>
Native gas tokens are represented as `0x0000000000000000000000000000000000000000` in the `token_address` in our assets schemas.
</Info>

### Table Columns

Unique Key: `unique_id`

| Column Name                | Description                                                                                                           |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| from\_address              | Address where the token is being transferred from.                                                                    |
| to\_address                | Address where the token is being transferred to.                                                                      |
| token\_address             | Token address of the asset transferred. `0x0000000000000000000000000000000000000000` for Native tokens on EVM chains. |
| token\_name                | Name of the asset transferred.                                                                                        |
| token\_symbol              | Token symbol of the asset transferred.                                                                                |
| raw\_amount                | Amount of tokens moved (unnormalized).                                                                                |
| raw\_amount\_str           | Amount of tokens moved (unnormalized) in string to retain precision.                                                  |
| amount                     | Amount of token moved, normalized.                                                                                    |
| amount\_str                | Amount of token moved, normalized in string to retain precision.                                                      |
| usd\_amount                | The USD amount of the tokens at the time of the transfer,                                                             |
| usd\_exchange\_rate        | The exchange rate used to calculate the usd\_amount.                                                                  |
| call\_type                 | Call type of the transaction. Non-call type will be indicated by NULL.                                                |
| transfer\_type             | The type of transfers. Typically includes `value_transfer`, `gas_burn`, `gas_payment_to_miner`.                       |
| transaction\_from\_address | The address of the sending party of this transaction.                                                                 |
| transaction\_to\_address   | The address of the receiving party of this transaction (could be a contract address).                                 |
| transaction\_hash          | Transaction hash that this transfer belongs to.                                                                       |
| transaction\_index         | The position of this transaction in the block. The first transaction has index 0.                                     |
| block\_timestamp           | The time when the block that contains this transaction was included on the blockchain.                                |
| block\_number              | The block number that the corresponding transaction of this transfer belongs to.                                      |
| block\_hash                | The block hash that the corresponding transaction of this transfer belongs to.                                        |
| unique\_id                 | Unique id generated to each transfer.                                                                                 |
