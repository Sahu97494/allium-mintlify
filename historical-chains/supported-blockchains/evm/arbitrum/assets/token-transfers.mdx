Our Arbitrum assets schema currently includes ETH and ERC20 Token Transfers.

<Info>
Note that native ETH on Arbitrum uses the null address `0x0000000000000000000000000000000000000000` as token\_address.
</Info>

`arbitrum.assets.eth_erc20_token_transfers` combines both ETH and ERC20 transfers on Arbitrum.

### Table Columns
