Our Polygon raw schema contains the following tables:

## Raw Blockchain Data

| Schema | Description                                           | Tables                                                      |
| ------ | ----------------------------------------------------- | ----------------------------------------------------------- |
| Raw    | Raw blockchain data.                                  | blocks, transactions, logs, traces                          |
| Raw +  | Deployed contracts with bytecode, decoded tokens data | contracts, erc20\_tokens, erc721\_tokens, erc\_1155\_tokens |
