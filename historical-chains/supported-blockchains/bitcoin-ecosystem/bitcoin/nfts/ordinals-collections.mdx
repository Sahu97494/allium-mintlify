---
title: "Ordinals Collections"
---

The `bitcoin.nfts.ordinals_collections `table contains ordinals collection data aggregated from various ordinals explorer/data sources.

## Table Columns

| Column Name        | Description                                                                                                    | Example                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| name               | Collection name of the inscription, if applicable.                                                             | ordfish                                                                                                         |
| slug               | Collection slug of the inscription, if applicable. The collection slug is a human-readable, unique identifier. | ordfish                                                                                                         |
| supply             | Total supply of the collection.                                                                                | 100                                                                                                             |
| icon               | Collection icon, if applicable.                                                                                | 5b182278c42d5a74ab4dd9f43826a0a2fce0158000001ed3bdf44873f1378d93i0                                              |
| genesis\_height    | Block height at the genesis of inscription.                                                                    | 788301                                                                                                          |
| genesis\_timestamp | Timestamp of the inscription                                                                                   | 2023-05-04 23:48:48                                                                                             |
| description        | Description of the collection, if applicable.                                                                  | Ordinary literary fish. Look up an ordfish by entering its satoshi code into ordinals.com or aesthetic.computer |
| twitter\_link      | Collection Twitter link, if applicable.                                                                        | [https://twitter.com/digitpain](https://twitter.com/digitpain)                                                  |
| discord\_link      | Collection Discord link, if applicable.                                                                        | [https://discord.gg/aesthetic-computer](https://discord.gg/aesthetic-computer)                                  |
| website\_link      | Collection Website link, if applicable.                                                                        | [https://aesthetic.computer](https://aesthetic.computer)                                                        |
| unique\_id         | Unique ID of the collection.                                                                                   | ordfish                                                                                                         |
