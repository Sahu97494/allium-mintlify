---
title: "Latest Balances"
description: "  The latest balances table records the latest block height at which an address's balance changed. Includes USD value where applicable. Can be used to analyze latest changes in balance."
---

Sample query:

```sql
select * from bitcoin.assets.balances_latest
where last_activity_block_timestamp >= current_timestamp - interval '5 hours';
```
